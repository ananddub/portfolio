# Anand Dubey — Developer Portfolio

A modern, responsive portfolio website built with **Next.js 15**, **React 19**, **Tailwind CSS**, and **Framer Motion**.

---

## 🚀 Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **UI & Animations**: React 19, Tailwind CSS, Framer Motion, Lenis Smooth Scroll
- **Content**: MDX, Lucide Icons, Simple Icons
- **Deployment**: Vercel

---

## 🛠 Features

- **Hero Section**: Dynamic particle bursts, text scramble effects, typewriter headers, and live theme toggler.
- **Projects Showcase**: Interactive modal views, category filtering, and direct links to engineering repositories.
- **Skills Matrix**: Categorized technical competencies across Mobile, Backend, Databases, and DevOps.
- **Work Experience**: Interactive timeline showcasing professional application development roles.
- **Open Source Systems**: Live GitHub cards linking to featured architectures (`incord`, `openoxide`, `cartwave`).

---

## 💻 Getting Started

```bash
# Install dependencies
bun install # or npm install

# Start development server
bun dev # or npm run dev
```
